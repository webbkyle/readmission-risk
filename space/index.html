Model card

LightGBM, trained on 2,108 synthetic discharges. Holdout is 57 patients the model never saw, frozen for all future champion/challenger comparisons. The high AUC reflects Synthea's strong patient-level autocorrelation — this demo is about the system (features → serving → monitoring → retraining), not a clinical claim. Not validated for clinical use.

Synthetic patients generated by Synthea (FHIR R4). No real patient data. Model runs fully client-side via ONNX Runtime Web.
